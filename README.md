# KORYO STRONG Calendar Sync — Privacy Policy

Last updated: 2026-11-10

## English

KORYO STRONG Calendar Sync is a personal tool used only by its developer. It is not offered to the public.

**What it accesses.** With the developer's own consent, the app reads Google Calendar data using the read-only scope `https://www.googleapis.com/auth/calendar.readonly`. It never creates, changes, or deletes calendar data.

**What it stores.** For each event it keeps only the start time, end time, a busy flag, a tentative flag, and a generic category (sport, workout, or other). It does not store event titles, descriptions, locations, attendees, meeting links, or contact details. The data is stored in a private database that only the developer can sign in to.

**How it is used.** The data is used only to show training and sport days in the developer's own workout planner.

**Sharing.** The app does not sell, share, or transfer Google user data to anyone. It does not use the data for advertising, and no person reads it except the developer.

**Limited Use.** The app's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including its Limited Use requirements.

**Retention and deletion.** Stored calendar data is replaced on each update. The developer can revoke access at any time at https://myaccount.google.com/permissions, and can ask for deletion of all stored data by contacting the address below.

**Contact.** gegenuver@gmail.com

## 日本語

KORYO STRONG Calendar Sync は、開発者本人だけが使う個人用ツールです。一般には提供していません。

**取得する情報。** 開発者本人の同意のもとで、Google カレンダーを読取専用の権限（`https://www.googleapis.com/auth/calendar.readonly`）で読み取ります。予定の作成、変更、削除は行いません。

**保存する情報。** 予定ごとに、開始時刻、終了時刻、予定ありの区別、仮予定の区別、一般的な分類（球技、筋トレ、その他）だけを保存します。予定のタイトル、説明、場所、参加者、会議 URL、連絡先は保存しません。保存先は、開発者だけがログインできる非公開のデータベースです。

**利用目的。** 開発者自身の筋トレ計画画面で、トレーニングや球技の日を表示するためだけに使います。

**第三者への提供。** Google ユーザーデータを、販売も共有もせず、第三者へ提供することもありません。広告にも使いません。開発者以外の人が読むこともありません。

**制限付き利用。** Google API から受け取った情報の利用と転送は、制限付き利用の要件を含め、[Google API サービスのユーザーデータポリシー](https://developers.google.com/terms/api-services-user-data-policy)に従います。

**保存期間と削除。** 保存した予定は、更新のたびに置き換えます。アクセスの取り消しは、いつでも https://myaccount.google.com/permissions で行えます。保存データの全削除は、下記の連絡先へ依頼できます。

**連絡先。** gegenuver@gmail.com
